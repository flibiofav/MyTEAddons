# MyTEAddons
A space to save my personal addons for Tablacus Explorer

* dropdown:<br>
		Adds "Folder Dropdown" to the type.<br>
    Coming from Explorer+QTTabbar, I missed the dropdown funcionality in the "toolbar" addon.<br>

    Use: Add a new item, select type "Folder dropdown" and choose a folder in the "options" button.
		On click, show a dropdown list with the content of the folder; on double-click, open the folder in a new tab.

* recyclebin:<br>
		Adds a toolbar icon to use the recycle bin
